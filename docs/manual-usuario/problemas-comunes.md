# Problemas comunes

| Qué ves | Qué hacer |
| --- | --- |
| API no disponible / error de conexión | Verificá que el equipo/servicio estén encendidos. En desarrollo deben correr API y Vite. No significa contraseña incorrecta. |
| Credenciales inválidas o cuenta bloqueada | Revisá usuario/PIN; después de cinco fallos esperá cinco minutos. No sigas probando contraseñas al azar. |
| Primero cambiar contraseña | Completá el cambio inicial o temporal para continuar. |
| Sesión vencida / acceso denegado | Volvé a ingresar; el administrador pudo cambiar tus credenciales/rol. Un cajero no puede abrir administración. |
| No puedo abrir caja | Ya hay una abierta en la sucursal. Pedí cerrar/consultar el turno anterior. Usá tu cuenta Cajero. |
| No aparece un producto o combo | Puede estar inactivo, su categoría desactivada, faltar opciones obligatorias o un componente no disponible. Administración ve la advertencia exacta en Catálogo. |
| No puedo confirmar elecciones | Cumplí mínimo/máximo de cada grupo y elegí todas las unidades de componentes. No se puede repetir una misma opción de modificador. |
| Error al convertir en combo | El producto se usa como componente activo de otro combo. Quitar primero la referencia; no se admiten combos anidados. |
| Cobro pendiente | Consultá resultado o reintentá la misma solicitud. No repitás el datáfono/SINPE ni creés otro cobro hasta verificar. |
| Conflicto de cobro | El mismo identificador se usó con otros datos. Pedí revisión antes de volver a cobrar. |
| No puedo anular / cambiar una venta | La sesión debe ser tuya y estar abierta. Una sesión cerrada conserva su historial sin cambios. |
| Anulé una tarjeta/SINPE pero el cliente no recibió devolución | La devolución es externa: reversá en datáfono o devolvé el SINPE y verificá el resultado. |
| Token de retiro vencido/usado | Pedí nueva autorización al administrador para ese retiro. No sirve para otra acción ni otra persona. |
| Imagen rechazada | Elegí un archivo PNG o JPG válido de hasta 1 MB. Renombrar otra extensión no convierte la imagen. |
| No puedo bajar el siguiente número | Es intencional para evitar repetir documentos. Solo se mantiene o aumenta. |
| Tiquete cortado o con URL arriba | Revisá vista previa, ancho 80 mm y desactivá encabezados/pies del navegador. Reporte en carta. |
| Contado y diferencia sin valor | Revisá si dice CERRADA SIN CONTEO; no se hizo conteo y esos importes no existen. |
| Hay diferencia al cerrar | Recontá monedas/billetes y revisá inicial, depósitos, retiros, vuelto y anulaciones antes de confirmar. No cambies ventas para ocultarla. Si ya cerraste, informá al administrador y conservá el reporte. |

Si persiste un error interno, anotá la hora, pantalla y TraceId si aparece. No envíes PIN ni contraseña en una captura. Para soporte técnico ver [Operación](../tecnico/operacion.md).
