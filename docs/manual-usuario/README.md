# Manual de Pollotikito

Pollotikito funciona en el equipo del restaurante, sin internet. Necesita que la aplicación y su base local estén encendidas. Los ejemplos muestran **Pollotikito Demo**, un negocio ficticio, con montos en colones.

1. [Primeros pasos e ingreso](primeros-pasos.md)
2. [Administración: usuarios, menú y negocio](administrador.md)
3. [Caja: vender, cobrar y cerrar](cajero.md)
4. [Problemas comunes](problemas-comunes.md)

Las 27 capturas se generaron con datos ficticios en una base de pruebas y con los campos de credenciales vacíos. El procedimiento reproducible está en [Pruebas y capturas](../tecnico/pruebas.md). No contienen datos del restaurante real.
